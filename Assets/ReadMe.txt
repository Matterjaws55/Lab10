The game uses an ISaveable interface to make objects like the player and targets provide their data when saving. When the player saves, the GameManager collects the player's position and score, plus the positions of all active targets, and stores them in a SaveData object. The player’s score is saved in a binary file, and the player and target positions are saved to a JSON file using a TransformSaver class. When the player laods, the GameManager reads the data back from the JSON and binary files, restores the player’s position and score, and repositions or respawns the targets to match the saved state. This lets the game return to exactly where it was when saved.
